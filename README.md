# Algebra HTML Explainers

Interactive, self-contained algebra lessons that work in a browser. The first lesson, [Four ways to graph a quadratic](index.html), includes a graphing lab and a vertical-line test for functions.

## View the lessons

Open `index.html` directly, or use the GitHub Pages site linked in this repository's About section.

## Add another explainer

1. Create a self-contained HTML file in an `explainers/` folder, using a descriptive name such as `solving-linear-equations.html`.
2. Add a link to it in this README and in the navigation on `index.html`.
3. Commit and push the files. GitHub Pages will serve the new page at `/explainers/your-file-name.html`.

The pages use local HTML, CSS, SVG, and JavaScript, so they do not need a build process or external libraries.
