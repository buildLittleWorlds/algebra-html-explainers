Four ways to graph a quadratic

Every quadratic makes a parabola. The graph stays the same whether you build it from a table, locate its vertex, find its intercepts, or transform the parent curve. Each method simply reveals different useful points.

When is a graph a function?

Every quadratic above is y as a function of x: each x in its domain gives exactly one y. Move the orange vertical line. If it hits a graph twice at any x, that graph is not a function of x. This is the vertical line test.

Two useful distinctions: A vertical line that misses a graph is fine; that x is simply outside the graph’s domain. Different x-values may also share one y-value. The test asks whether one x-value has more than one y-value.

Quick challenge: A vertical line touches the circle once. Does that make the circle a function?

No. A line at x = 2.5 touches it once, but a line at x = 0 meets it twice, at y = −2.5 and y = 2.5. One line with two intersections is enough to show it is not a function of x.

How to choose a starting point

You can use more than one method. A quick graph often begins with the vertex, then adds intercepts or a few symmetric points.

Method 1

Make a table

Pick x-values, substitute each into the equation, and plot the resulting (x, y) points. Choose values on both sides of the vertex so you see the U shape.

x → ax² + bx + c → y
Useful for any quadratic; often the easiest first method. A table alone can miss the exact vertex if you choose poorly.
Method 2

Find the vertex

The vertex is the lowest or highest point. Its x-coordinate is h = −b/(2a); substitute h to get k. Draw the symmetry line x = h and reflect a known point across it.

vertex (h, k), axis x = h
Useful when you need the maximum or minimum, and when the x-intercepts are awkward or absent.
Method 3

Find the intercepts

The y-intercept is (0, c). To find x-intercepts, solve ax² + bx + c = 0 by factoring or with the quadratic formula. The discriminant b² − 4ac tells how many real x-intercepts exist.

x = (−b ± √(b² − 4ac))/(2a)
Useful when roots matter. If the discriminant is negative, combine the y-intercept with the vertex instead.
Method 4

Transform the parent graph

Rewrite the equation as y = a(x − h)² + k. Start with y = x², then shift h units horizontally, multiply heights by |a|, reflect over the x-axis if a is negative, and shift k units vertically.

y = a(x − h)² + k
Useful when the equation is already in vertex form or when you want to see how coefficients change the curve.

What changes the shape?

The sign and size of a affect every method.

a > 0: the parabola opens up, so the vertex is a minimum.
a < 0: it opens down, so the vertex is a maximum.
|a| > 1: narrower than y = x²; 0 < |a| < 1: wider.

A complete graph, step by step

Use y = x² − 4x + 3. Several methods confirm the same picture.

  1. Vertex: h = −(−4)/(2·1) = 2. Then k = 2² − 4(2) + 3 = −1. Plot (2, −1) and draw the axis x = 2.
  2. Intercepts: x² − 4x + 3 = (x − 1)(x − 3), so plot (1, 0) and (3, 0). With x = 0, plot the y-intercept (0, 3).
  3. Symmetry: (0, 3) is two units left of x = 2, so (4, 3) is also on the graph. Draw a smooth U-shaped curve through these points.
  4. Transformation check: complete the square: x² − 4x + 3 = (x − 2)² − 1. The parent curve y = x² moves right 2 and down 1.
Key points: (2, −1), (1, 0), (3, 0), (0, 3), (4, 3). The parabola opens upward.

Quick check

Suppose a quadratic has vertex (3, −2) and contains the point (1, 6). Which other point must be on its graph?

(5, 6). The axis of symmetry is x = 3. The point (1, 6) is two units to its left, so a matching point is two units to its right.
